# RTS DarkZone Gaming

A modern dark gaming website concept focused on **PC and Mobile Simulator Games**, especially:

- Euro Truck Simulator 2
- Proton Bus Simulator
- Bus Simulator Indonesia

This project includes a premium one-page layout with animations, 3D-style hover effects, gallery previews, gameplay cards, mod filtering, downloads center, and a contact form.

## Features

- Dark futuristic simulator-themed UI
- Responsive layout for desktop, tablet, and mobile
- Animated hero section
- CSS-based 3D hover tilt effects
- Scroll reveal animations
- Dynamic gallery with lightbox preview
- Gameplay video cards
- Search + filter system for mods and maps
- Download center section
- Contact form validation
- Loading screen
- Toast notifications for demo buttons

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

No framework is required for this version.
